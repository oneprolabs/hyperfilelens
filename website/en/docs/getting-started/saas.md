## Before you start

- New users need an available Google account. Existing users need their current sign-in account.
- Prepare a host whose files you want to protect. Agent supports Windows, Linux, and macOS hosts.
- Prepare object storage that the SaaS can reach over the public network, together with its endpoint, region, bucket, and access credentials.
- Make sure the backup host can reach both the SaaS console and the object storage service.
