# 限制与安全建议

本页说明使用产品时需要注意的功能边界。运行平台和存储类型请查看[支持范围](/zh/docs/reference/support-matrix)。

## 功能边界

- 文件级备份不自动保证数据库、虚拟机或业务应用的一致性。
- 未绑定 Proxy 的 NAS 连接仅适用于产品页面明确支持的 Linux 备份主机。
- 当前版本不能把目标位置中已有的备份仓库直接导入为新的目标存储。
- 只有成功或部分成功，并且包含已备份文件的快照才能用于恢复。
- Private Data Gateway 只读取用户选择的备份快照，不会自动访问备份主机上的实时文件。
- 智能洞察的回答由 AI 模型生成，重要结论必须结合原始文件和引用核对。

## 凭据与密钥

- 对象存储和外部模型服务使用专用访问凭据，并只授予完成任务所需的权限。
- 不在截图、聊天或公开问题中提供密码、访问令牌和存储密钥。
- 轮换凭据后，重新验证存储连接，并执行一次备份或洞察任务。

## 网络与 TLS

社区版默认提供的证书用于完成初始安装和访问。正式环境应配置与实际访问域名匹配、且浏览器和组件均信任的 TLS 证书。

按[网络与端口](/zh/docs/deployment/network)开放必要连接，并限制允许访问的来源网络。建议保持 TLS 校验开启，不要通过长期关闭校验解决证书问题。

## 数据与删除

备份仓库、快照、恢复后的文件、洞察会话和 Data Gateway 工作区是不同的数据副本。删除其中一项，不代表其他副本会同步删除。

删除资源前应查看界面列出的影响范围。卸载组件时使用产品提供的维护命令，只清理安装程序明确列出的产品目录。

## 恢复验证

备份任务成功不能替代恢复验证。应定期把测试文件恢复到独立目录，核对文件内容，并保留验证结果。
