# 核心概念

这些概念用于解释产品行为。日常操作仍建议从备份、恢复或智能洞察的任务流程开始。

## 数据保护

| 概念 | 说明 |
| --- | --- |
| 备份源 | 需要保护的主机文件或 NAS 数据入口 |
| 目标存储 | 保存备份仓库的位置，包括对象存储、NAS 和 Proxy 本地磁盘 |
| 备份配置 | 一个源端范围与目标存储、策略、过滤规则和可选恢复计划的组合 |
| 备份策略 | 规定调度、扫描、过滤和传输行为的可复用设置 |
| 任务 | 一次备份、恢复或仓库维护的执行记录 |
| 快照 | 某次备份产生的可浏览历史时间点 |
| 恢复任务 | 从指定快照把选定范围写入目标节点和目录的一次执行 |
| 恢复计划 | 预设恢复范围、目标位置和重名策略，并从最新可用快照执行 |

配置描述期望状态，任务记录一次执行，快照才是可用于浏览和恢复的数据时间点。删除或修改配置不会改变已经恢复到其他位置的文件。

## 节点

- **Agent**运行在受保护主机上，读取本机文件并执行备份或恢复。
- **Proxy**连接 NAS、承载本地磁盘仓库，或向其他源端提供 Repository Server 访问。
- **Data Gateway**准备用户从备份快照中选择的数据，供 AI Copilot 使用。

节点在线表示控制通道可用，不代表它一定能访问所有源路径和目标仓库。备份前还需要完成数据路径验证。

## 智能洞察

- **Copilot 会话**关联一个备份源、具体快照、文件范围和 Data Gateway。
- **公共 Data Gateway**由平台提供并维护。
- **私有 Data Gateway**部署在用户可控网络中，用于访问私有仓库。
- **引用**帮助定位回答来源，但不代替人工核实。

Insights 处理的是备份副本。生产数据变化后，需要产生新快照并明确选择，已有会话不会自动切换到最新生产内容。
