# 核心概念

以下概念用于理解产品页面和任务之间的关系。需要完成具体操作时，请进入对应的产品使用指南。

## 账户与组织

| 概念 | 说明 |
| --- | --- |
| 组织 | 用户、备份资源、任务和业务数据的工作空间 |
| 成员 | 可以进入组织并使用授权功能的用户 |
| 角色 | 决定成员可以查看或执行哪些组织操作 |

## 数据保护

| 概念 | 说明 |
| --- | --- |
| 备份源 | 需要保护的主机文件或 NAS 数据 |
| 目标存储 | 保存备份仓库的位置，包括对象存储、NAS 和 Proxy 本地磁盘 |
| 备份配置 | 备份范围、目标存储、策略和可选恢复计划的组合 |
| 备份策略 | 定义执行时间、文件筛选、保留和传输规则的可复用设置 |
| 任务 | 一次备份、恢复或存储维护操作的执行记录 |
| 快照 | 某次备份产生的可浏览历史时间点 |
| 恢复任务 | 将指定快照中的文件或目录恢复到目标主机的一次执行 |
| 恢复计划 | 预设恢复范围、目标位置和重名策略，并从最新可用快照执行 |

备份配置决定如何执行备份，任务记录每次执行过程，快照保存可以浏览和恢复的数据时间点。

## 节点

- **Agent**安装在需要保护的主机上，访问本机文件并执行备份或恢复任务。
- **Proxy**连接 NAS 或本地磁盘，使这些存储可以作为备份源或目标存储。
- **公共 Data Gateway**由平台提供，是智能洞察的默认数据处理方式。
- **私有 Data Gateway**部署在用户管理的网络中，用于访问公共网关无法连接的备份仓库，或在自有网络中处理数据。

组件显示在线，表示已经连接控制平面；是否能够访问备份源或目标存储，仍以对应页面的连接验证和实际任务结果为准。

## 智能洞察

- **洞察会话**关联一个备份源、具体快照、文件范围和 Data Gateway。
- **数据范围**是用户从快照中明确选择供当前会话使用的文件和目录。
- **引用**用于定位回答所依据的文件内容，但不代表结论已经过人工核实。

智能洞察使用备份快照中的数据，不直接读取备份主机上的实时文件。生产文件发生变化后，需要先生成新快照，再创建或更新相应的数据范围。
