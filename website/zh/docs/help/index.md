# 帮助中心

遇到问题时，先确认它属于“需要查清产品行为”，还是“某个步骤执行失败”。

## 产品参考

适合在部署前、配置时或评估产品边界时查阅：

- [核心概念](/zh/docs/reference/)：理解备份源、目标存储、任务、快照、恢复和 Data Gateway。
- [支持范围](/zh/docs/reference/support-matrix)：确认操作系统、架构、备份源和目标存储支持情况。
- [限制与安全建议](/zh/docs/reference/limitations-security)：了解产品边界、凭据、网络、删除和恢复责任。

## 问题排查

适合已经出现错误、任务失败或页面不可用时使用：

- [安装与节点](/zh/docs/troubleshooting/installation-nodes)
- [备份、存储与恢复](/zh/docs/troubleshooting/protection)
- [智能洞察与 Data Gateway](/zh/docs/troubleshooting/insights)
- [账户与登录](/zh/docs/troubleshooting/account-sign-in)

排查时先记录产品版本、发生时间、页面位置、资源名称和错误编号。每次只修改一个条件，并在修改后重新验证。

公开提交问题前，请删除密码、访问令牌、对象存储密钥、完整 `.env`、客户文件名和私有地址。
