# 产品使用

HyperFileLens 以备份快照为中心：先把源端数据持续写入目标存储，再使用快照恢复文件或开展智能洞察。

## 备份与恢复

从[管理备份源](/zh/docs/backup-restore/sources)和[管理目标存储](/zh/docs/backup-restore/targets)开始，创建备份配置并生成可浏览快照。只有完成实际恢复验证，才能确认备份数据真正可用。

进入[备份与恢复](/zh/docs/backup-restore/)查看完整流程。

## 智能洞察

智能洞察使用已有备份快照，不直接读取生产目录。用户选择具体快照和数据范围后，通过 Data Gateway 准备数据并创建洞察会话。

进入[智能洞察](/zh/docs/insights/)了解模型、网关、用量和会话管理。

## 业务关系

```text
备份源 → 目标存储 → 备份任务 → 快照
                                  ├─ 恢复文件和目录
                                  └─ 创建洞察会话
```

首次使用建议先完成[快速开始](/zh/docs/)，使用同一份测试数据走通备份、恢复和智能洞察。
