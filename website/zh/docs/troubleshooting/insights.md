# 智能洞察与 Data Gateway

创建会话失败时，先根据页面提示检查快照、数据范围、AI 模型和 Data Gateway。

## 无法创建会话

根据页面提示逐项确认：

- 已选择存在可用快照的备份配置。
- 已选择成功或部分成功，并且包含已备份文件的快照。
- 已从快照中选择至少一个文件或目录。
- 平台已配置可用的默认 AI 模型。
- 已选择可用公共 Data Gateway，或手动选择在线私有 Data Gateway。

当<span class="hfl-ui">自动</span>模式提示没有公共网关时，选择私有 Data Gateway 或联系管理员；反复刷新不会创建不存在的公共网关。

## 私有 Data Gateway 不可用

- 在<span class="hfl-path">洞察 → 数据网关</span>中确认网关和 AI 引擎状态正常。
- 确认网关能够连接控制平面和所选快照所在的备份仓库。
- 确认网关版本与控制平面兼容。
- 检查网关主机的磁盘空间。

网关安装未完成时，请查看[安装与节点](/zh/docs/troubleshooting/installation-nodes)。

## 数据准备长时间未完成

- 使用少量文件或一个较小目录重新验证。
- 检查所选文件是否过大、损坏、加密或不受当前解析能力支持。
- 检查备份仓库的访问速度和 Data Gateway 运行状态。
- 不要重复创建相同范围的多个会话，以免增加并发负载。

## 回答缺少内容或依据

- 核对会话绑定的快照时间是否正确。
- 核对文件是否实际出现在所选快照和数据范围中。
- 缩小问题范围，并明确要求提供来源。
- 图片或扫描 PDF 需要可用多模态模型。
- 回到原文件核实重要结论。

## 数据边界疑问

确认当前使用公共还是私有 Data Gateway，以及 AI 模型由谁提供。判断数据处理位置时，需要同时考虑网关部署位置、模型服务地址和组织网络配置；使用私有网关并不代表外部模型服务也位于私有网络。
