# 智能洞察与 Data Gateway

## 无法创建会话

根据页面提示逐项确认：

- 已选择备份源。
- 已选择成功或部分成功且包含可用目录的快照。
- 至少选择一个文件或目录，并且目录浏览完成。
- 平台已配置默认 Agent 模型。
- 已选择可用公共 Data Gateway，或手动选择在线私有 Data Gateway。

当“自动”模式提示没有公共网关时，选择私有 Data Gateway 或联系管理员；反复刷新不会创建不存在的公共网关。

## 私有 Data Gateway 不可用

- 检查网关节点是否在线。
- 检查 Agent、Docker 和 AI 引擎容器状态。
- 检查网关到控制平面和备份仓库的网络。
- 确认网关版本与控制平面兼容。
- 检查工作区磁盘空间和权限。

## 数据准备长时间未完成

- 首次验证缩小到一个小目录或少量文件。
- 检查所选文件是否过大、损坏、加密或不受当前解析能力支持。
- 检查快照仓库访问速度和 Data Gateway 资源使用。
- 不要重复创建相同范围的多个会话，以免增加并发负载。

## 回答缺少内容或依据

- 核对会话绑定的快照时间是否正确。
- 核对文件是否实际出现在所选快照和数据范围中。
- 缩小问题范围，并明确要求提供来源。
- 图片或扫描 PDF 需要可用多模态模型。
- 回到原文件核实重要结论。

## 数据边界疑问

确认当前使用公共还是私有 Data Gateway，以及模型是自托管还是外部 API。需要判断数据是否离开私有网络时，必须结合网关部署位置、模型提供商和组织网络配置，不能只根据页面中的“私有网关”名称推断完整数据路径。
