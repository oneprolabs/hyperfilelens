# 账户与登录

## 无法打开控制台

1. 在控制平面主机运行 `sudo /opt/hyperfilelens/install.sh status`。
2. 使用安装程序实际输出的租户控制台地址，不要混用管理控制台或 SourceLens 地址。
3. 检查 DNS、端口、防火墙和反向代理。
4. 检查浏览器是否信任当前 TLS 证书，以及访问名称是否在证书范围内。

## 密码无法登录

- 确认登录的是 HyperFileLens 租户控制台，而不是捆绑的 SourceLens 控制台。
- 检查账户输入和大小写，避免复制前后空格。
- 首次安装使用安装程序输出的初始账户，修改密码后使用新密码。
- 多次失败后不要直接修改数据库。由具备权限的管理员使用当前版本支持的账户恢复流程处理。

公开提交问题时不要提供账户密码、Cookie、访问令牌或完整登录请求。

## 中文界面未出现

在控制平面检查语言包：

```bash
sudo /opt/hyperfilelens/install.sh lang-pack list
```

确认 `zh-hans` 已安装且与当前产品版本兼容，然后刷新浏览器并从语言入口选择简体中文。升级后出现翻译缺失时，应检查语言包版本，而不是手工修改前端构建产物。

## 页面显示旧版本

产品升级后，浏览器可能仍持有旧前端资源。根据页面提示重新加载；如果仍失败，清除该站点缓存或使用新会话访问。不要在备份或恢复任务运行中随意重启服务来解决单个浏览器缓存问题。
