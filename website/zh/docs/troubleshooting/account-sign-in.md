# 账户与登录

## 无法打开控制台

打开安装结果中 `Access` 区域内 `HyperFileLens` 对应的 `URL`。控制台无法打开时：

1. 在安装主机运行 `sudo /opt/hyperfilelens/install.sh status`，确认服务状态正常。
2. 检查访问地址、端口和反向代理是否与当前部署一致。
3. 确认浏览器能够连接该地址，并信任当前 TLS 证书。

## 无法登录

- 首次登录使用安装结果中列出的初始账户和密码。
- 已经修改初始密码时，使用修改后的密码，并检查输入内容是否包含多余空格。
- 确认打开的是 `HyperFileLens` 下的 `URL`，而不是 `Platform Ops` 平台管理地址。
- 无法恢复账户时，不要直接修改数据库；由管理员按照当前版本支持的账户恢复方式处理。

## 无法切换中文

社区版环境先检查简体中文语言包：

```bash
sudo /opt/hyperfilelens/install.sh lang-pack list
```

确认 `zh-hans` 已安装且与当前产品版本兼容，然后刷新页面并从语言入口选择简体中文。升级后出现翻译缺失时，应检查语言包版本。

## 页面显示旧版本

产品升级后，浏览器可能仍在使用旧页面资源。先根据页面提示重新加载；如果仍未更新，清除该站点缓存或使用新的浏览器会话访问。单个浏览器显示异常时，通常不需要重启服务。
