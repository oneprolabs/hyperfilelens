# 备份、存储与恢复

先在对应页面重新执行连接验证；任务已经开始时，从任务详情中的失败步骤进行排查。

## 无法浏览源目录

- 确认 Agent 或 Proxy 在线。
- 确认所选路径存在，并且 Agent 的运行身份具备读取权限。
- NAS 备份源应确认 Proxy 能够连接共享地址，并且协议、共享路径和凭据正确。
- 中文或其他非 ASCII 文件名显示异常时，确认 Proxy 主机支持 UTF-8 文件名并重新连接 NAS。
- 确认输入的路径格式与目标主机操作系统一致。

## 对象存储验证失败

按错误类型检查：

- **凭据被拒绝**：Access Key、Secret Key 或临时凭据已失效。
- **权限不足**：身份不能列出存储桶或读写目标前缀。
- **存储桶不存在**：名称、区域或账户错误。
- **配置无效**：Endpoint、区域、URL 方式或 TLS 配置不匹配。
- **网络或超时**：执行验证的组件无法访问对象存储 Endpoint。
- **TLS 失败**：证书链、服务名称或主机时间错误。

对象存储时间偏差过大也会导致签名失败。先同步系统时间，再重试验证。

## NAS 或本地磁盘验证失败

- 确认绑定的 Proxy 在线。
- NAS 应确认共享地址、协议、共享路径和凭据正确。
- 本地磁盘应确认目录存在、可写且剩余空间充足。
- 其他备份主机或 Private Data Gateway 需要访问 Proxy 存储时，确认<span class="hfl-ui">存储仓库服务器地址</span>可从相应网络访问，并开放所需端口。
- 不要选择已存放其他业务数据或已有备份仓库的目录。

## 备份失败或部分成功

打开任务详情查看具体失败步骤和文件范围。常见原因包括源文件已删除、读取权限变化、文件被占用、目标存储连接中断或 Agent 离线。

部分成功快照只包含已经完成的范围。修复问题后重新执行备份，并验证新快照，不要假定失败部分会自动补入旧快照。

## 快照无法恢复

- 快照必须为成功或部分成功状态。
- 快照必须包含可以浏览的已备份文件或目录。
- 所选恢复范围必须属于该快照中的已备份路径。
- 恢复目标 Agent 必须在线，目标目录存在、可写且空间充足。
- 同一备份源已有恢复任务运行时，等待结束后再提交。

恢复任务被停止后，目标目录可能保留未完整写入的文件。核对目标目录后，再根据重名策略重新执行恢复。
