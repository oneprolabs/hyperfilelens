# 网络与端口要求

HyperFileLens 同时包含控制连接和数据连接。浏览器能打开控制台，不代表备份源一定能够访问目标存储。

## 需要连通的路径

| 来源 | 目标 | 用途 |
| --- | --- | --- |
| 浏览器 | HyperFileLens 控制台 | HTTPS 页面与接口访问 |
| Agent、Proxy、Data Gateway | 控制平面 | 注册、状态上报和任务控制 |
| Agent 或 Proxy | 对象存储 | 写入备份与读取恢复数据 |
| Proxy | NAS | 访问源共享或目标共享 |
| 备份源 | Repository Server | 通过 Proxy 访问目标仓库 |
| Data Gateway | 备份仓库与模型服务 | 准备和分析所选备份数据 |

HTTPS 和对象存储通常使用 `443`；SMB 通常使用 `445`；NFS 通常使用 `2049`。实际端口可能因反向代理、存储服务和部署配置不同而变化，应以控制台生成的地址和当前环境配置为准。

## 配置原则

- 只开放实际需要的来源、目标和端口。
- 不要为了排障长期关闭 TLS 校验或放开全部防火墙规则。
- 使用源端实际可达的 Proxy 或 Repository Server 地址。
- 修改网络策略后重新验证节点、目标存储、备份和恢复。
