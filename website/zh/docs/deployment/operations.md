# 任务、告警与审计

<p class="hfl-doc-lead">日常运行中，先通过运营健康和告警发现异常，再从任务详情定位失败阶段；操作审计用于确认关键变更的执行人、时间和结果。</p>

## 检查运行健康

打开<span class="hfl-path">运维监控 → 运营健康</span>，查看当前告警、离线组件、备份源异常和近期失败任务。发现异常时，先打开对应资源或任务详情，不需要先登录主机查看日志。

## 查看任务

打开<span class="hfl-path">运维监控 → 任务列表</span>，可以按名称、状态、类型和时间筛选备份、恢复、组件维护及相关任务。

任务异常时，打开任务详情并依次检查任务状态、失败步骤、关联资源和错误信息。任务显示部分成功时，还需要确认未完成的资源范围；只有产品提供<span class="hfl-ui">取消</span>或<span class="hfl-ui">重试</span>操作时才执行相应处理。

## 告警与通知

在<span class="hfl-path">运维监控 → 告警</span>中查看当前及历史告警：

- **告警**：查看严重程度、影响资源、首次发生时间和当前状态。确认告警表示已经有人跟进，不代表问题已经消除；资源恢复后再将告警标记为已解决。
- **告警规则**：设置需要监测的资源、触发条件和严重程度。
- **通知渠道**：配置告警通知的接收方式。
- **投递历史**：确认通知是否发送成功，并查看失败原因。

处理告警后，应重新检查相关资源状态，并验证后续任务能够正常完成。

## 查看操作审计

打开<span class="hfl-path">运维监控 → 操作审计</span>，按用户、操作类型、资源、结果和时间查询关键操作。需要留存或进一步分析时，可以导出当前筛选范围内的审计记录。

## 进一步排查

控制台信息不足以定位问题时，记录相关资源、任务编号、错误信息和发生时间，再进入[问题排查](/zh/docs/troubleshooting/)查找对应场景。只有排查步骤明确要求时，才需要收集控制平面或组件日志。
