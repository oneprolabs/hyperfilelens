# 任务、告警与日志

日常运维以任务结果和异常状态为主。先在控制台定位失败阶段，再收集必要日志。

## 任务

在<span class="hfl-path">租户运维 → 任务</span>中查看备份、恢复和相关后台任务的状态、开始时间、结束时间和错误信息。部分成功任务需要继续检查具体失败范围。

## 告警与通知

告警用于提示节点离线、任务失败或其他需要关注的运行异常。处理后应确认相关资源恢复正常，并验证下一次任务结果。

## 日志与审计记录

日志用于分析具体失败原因，审计记录用于确认关键操作由谁在何时执行。公开提交问题前，应删除账户、令牌、存储凭据、客户文件名和私有地址。

无法判断失败位置时，从[问题排查](/zh/docs/troubleshooting/)开始。
