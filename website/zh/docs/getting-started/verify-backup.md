# 验证备份结果

任务完成只表示执行已经结束，还需要确认快照实际包含预期文件。

## 检查任务

打开备份任务详情并确认：

- 状态为成功；如果是部分成功，需要查看具体失败目录。
- 备份源、目标存储和执行时间正确。
- 扫描与传输数据量和测试目录大致相符。
- 没有未处理的权限、网络或存储错误。

## 检查快照

1. 打开此次任务生成的快照。
2. 浏览快照目录。
3. 找到准备好的测试文件。
4. 核对文件名、目录层级、大小和时间。

确认快照内容正确后，继续[恢复测试文件](/zh/docs/getting-started/first-restore)。
