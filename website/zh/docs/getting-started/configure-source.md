# 配置备份源

打开<span class="hfl-path">数据保护 → 备份向导</span>并选择<span class="hfl-ui">创建备份配置</span>。本次只选择快速开始准备的测试目录，不要选择整个系统盘。

## 选择备份内容

1. 选择刚添加的 Windows 备份源。
2. 展开目录树并找到 `C:\HFL-Quickstart`。
3. 将测试目录添加到备份范围。
4. 核对目录中的测试文件是否可以正常浏览。
5. 首次使用可暂不关联复杂的调度策略和文件过滤规则。
6. 继续进入目标端步骤。

## 完成标准

- 已选中正确的 Windows 主机。
- 备份范围只包含本次准备的测试目录。
- 测试文件的名称、目录层级和预计数据量符合预期。

如果目标端步骤中没有可用存储仓库，请不要退出向导。下一步直接在当前流程中[添加目标存储](/zh/docs/getting-started/add-target)。
