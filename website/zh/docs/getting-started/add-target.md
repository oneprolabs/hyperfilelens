# 配置目标存储

目标存储用于保存备份快照。首次使用可选择对象存储、NAS，或者 Proxy 主机上的专用本地磁盘目录。

## 选择目标类型

- **对象存储**：填写服务商、端点、区域、存储桶、对象前缀和凭据。
- **NAS**：填写共享地址和协议，并按网络条件绑定 Proxy。
- **本地磁盘**：选择 Proxy 主机及其上的专用绝对路径。

## 验证目标

1. 打开目标存储页面并选择目标类型。
2. 填写连接信息和凭据。
3. 使用专用于 HyperFileLens 的路径或对象前缀。
4. 执行页面提供的连接与写入验证。
5. 确认验证成功后保存。

不要选择包含其他业务文件的现有目录，也不要让多个独立仓库共用同一对象前缀。
