# 添加目标存储

目标存储用于保存备份快照。本章使用对象存储作为示例，并从备份向导的目标端步骤直接完成添加。

## 准备连接信息

提前准备服务商、服务地址（Endpoint）、区域（Region）、存储桶（Bucket）、对象前缀和访问凭据。使用专用于 HyperFileLens 的存储桶或对象前缀，不要与其他备份仓库或业务文件混用。

## 在向导中添加

1. 在备份向导的目标端步骤选择“添加存储仓库”。
2. 选择对象存储并填写连接信息和凭据。
3. 执行页面提供的连接与写入验证。
4. 确认验证成功后保存。
5. 返回原备份向导，将新建的对象存储分配给 Windows 备份源。
6. 继续完成后续步骤。

访问密钥属于敏感信息，不要出现在截图、聊天、文档示例或公开 Issue 中。
