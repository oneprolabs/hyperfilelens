# 创建洞察会话

智能洞察使用已经生成的备份快照，不直接读取 Windows 主机上的生产目录。本次继续使用首次备份生成的快照。

## 开始前检查

- 首次备份快照可用，并包含准备分析的测试文件。
- 平台已经配置默认 AI 模型。
- 当前环境存在可用的 Data Gateway。

如果页面提示模型或 Data Gateway 尚未就绪，请先查看[准备快照](/zh/docs/insights/prepare)，并按提示完成模型或网关配置。

## 创建会话

1. 打开<span class="hfl-path">洞察 → AI Copilot</span>并选择<span class="hfl-ui">新建对话</span>。
2. 选择刚创建的备份配置和快照。
3. 从快照中选择一个测试文件或边界明确的小目录。
4. 选择当前可用的 Data Gateway。
5. 核对快照时间、数据范围和网关后创建会话。
6. 提出一个能够从原文件直接核对的问题。

例如，选择 `device-inventory.csv` 后询问：“文件中记录了多少台设备？请列出设备名称并说明依据。”

## 完成标准

- 会话创建成功，数据准备完成。
- 回答与所选文件内容一致。
- 可以回到原文件核对回答中的关键事实。

至此，已经使用同一份测试数据完成备份、恢复和智能洞察。更多用法请查看[智能洞察](/zh/docs/insights/)。
