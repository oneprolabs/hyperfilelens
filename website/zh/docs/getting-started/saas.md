# 使用官方 SaaS

官方 SaaS 无需安装控制平面。点击文档右上角的“免费试用”，注册或登录后即可进入 HyperFileLens 控制台。

## 开始前准备

- 一台需要保护的 Linux、Windows 或 macOS 主机，或者一个可访问的 NAS 共享。
- 一处可用目标存储，例如对象存储、NAS 或 Proxy 主机上的专用磁盘目录。
- 允许备份节点访问官方 SaaS、目标存储及所需业务网络的网络条件。

## 进入控制台

1. 点击“免费试用”。
2. 注册账户，或者使用已有账户登录。
3. 按页面提示进入组织工作台。
4. 确认可以看到数据保护相关页面。

进入控制台后，继续[登录与初始设置](/zh/docs/getting-started/sign-in)。后续添加备份源、配置目标存储、备份和恢复的主流程与 Community 一致。

当前快速开始提供官方 SaaS 和 Community 两种入口。
