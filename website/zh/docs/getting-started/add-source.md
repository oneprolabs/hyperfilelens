# 添加备份源

本章以 Windows 主机作为备份源。此步骤只负责安装 Agent、完成注册并确认主机在线；需要保护的目录将在下一步选择。

## 接入 Windows 主机

1. 打开<span class="hfl-path">数据保护 → 源端资源</span>。
2. 选择添加源端主机并进入部署向导。
3. 选择 Windows。
4. 复制页面生成的当前部署命令，在需要保护的主机上运行。
5. 返回控制台，等待节点显示在线。
6. 确认主机状态为在线。

部署命令可能包含注册信息，不要复用旧截图中的命令，也不要公开分享。

## 完成标准

- 备份源状态在线。
- 控制台显示的主机名称和系统信息正确。
- Agent 没有待处理的安装或注册错误。
