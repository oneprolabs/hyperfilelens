# 添加备份源

首次使用建议选择一台测试主机，并只保护一个内容明确的小目录。也可以添加一个能够通过 Proxy 访问的 NAS 共享。

## 添加主机

1. 打开<span class="hfl-path">数据保护 → 源端资源</span>。
2. 选择添加源端主机并进入部署向导。
3. 选择 Linux、Windows 或 macOS。
4. 复制页面生成的当前部署命令，在需要保护的主机上运行。
5. 返回控制台，等待节点显示在线。
6. 打开目录浏览，确认能够看到准备好的测试目录和文件。

部署命令可能包含注册信息，不要复用旧截图中的命令，也不要公开分享。

## 添加 NAS

添加 NAS 时，需要填写共享地址、协议和凭据，并选择能够访问该共享的 Proxy。保存前确认共享路径可达、凭据有效且目录能够浏览。

## 完成标准

- 备份源状态在线。
- 可以浏览并选择测试目录。
- 文件名称、目录层级和预计数据量符合预期。
