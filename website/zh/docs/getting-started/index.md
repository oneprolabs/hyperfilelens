# 开始使用

本节帮助你从空白环境走到第一个可验证的备份快照。完成后，你将拥有一个在线备份源、一处可写的目标存储和至少一个成功或部分成功的快照。

## 开始前准备

- 一台符合要求的 Ubuntu amd64 主机，用于运行 HyperFileLens 控制平面。
- 一台需要保护的 Linux、Windows 或 macOS 主机，或者一个可访问的 NAS 共享。
- 一处目标存储：对象存储、NAS 或 Proxy 主机上的本地磁盘。
- 控制平面、节点和目标存储之间必要的 HTTPS、存储协议和业务网络连通性。

具体平台和架构请查看[部署要求](/zh/docs/getting-started/requirements)与[支持范围](/zh/docs/reference/support-matrix)。

## 最短使用路径

1. [安装 HyperFileLens](/zh/docs/getting-started/install)。
2. 使用安装程序输出的地址和初始账户登录，并立即修改公开默认密码。
3. 在<span class="hfl-path">数据保护 → 源端资源</span>中部署或注册源端 Agent，或者添加 NAS 源。
4. 在目标存储页面准备对象存储、NAS 或本地磁盘仓库。
5. 打开<span class="hfl-path">数据保护 → 备份向导</span>，创建备份配置。
6. 执行“立即备份”，等待任务完成。
7. 打开快照详情，确认时间、数据量和可浏览目录符合预期。
8. 选择少量非关键文件执行一次恢复验证。

## 预期结果

完成本节后，应同时满足：

- 控制平面状态正常，浏览器可以访问租户控制台。
- 备份源显示在线，目录可以浏览。
- 目标存储验证通过。
- 备份任务完成并生成快照。
- 能够从快照浏览或恢复至少一个文件。

如果任一环节失败，先记录界面中的错误编号和失败阶段，再进入[常见问题与排障](/zh/docs/troubleshooting/)。
