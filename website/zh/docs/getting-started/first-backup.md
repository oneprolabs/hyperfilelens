# 创建并运行首次备份

本次只选择准备好的测试目录。先完成小范围闭环，再扩大到实际需要保护的数据。

## 保存备份配置

1. 从对象存储添加页面返回备份向导。
2. 确认 Windows 备份源已经分配到刚添加的对象存储。
3. 首次使用可以暂不配置恢复计划。
4. 在确认信息中核对备份源、测试目录、策略和目标存储。
5. 提交并等待备份配置保存完成。

## 运行备份

进入开始备份阶段，选择刚创建的配置并执行“立即备份”。运行期间不要关闭 Windows Agent，也不要修改对象存储凭据。

等待任务结束后，继续[检查任务与快照](/zh/docs/getting-started/verify-backup)。
