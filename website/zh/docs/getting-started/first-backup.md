# 创建首次备份

本次只选择准备好的测试目录。先完成小范围闭环，再扩大到实际需要保护的数据。

## 创建备份配置

1. 打开<span class="hfl-path">数据保护 → 备份向导</span>，选择创建备份配置。
2. 选择刚刚添加的备份源。
3. 从目录树中选择测试目录。
4. 选择已经验证通过的目标存储。
5. 首次验证使用简单的手动执行方式，暂时不必配置复杂调度。
6. 核对备份源、目录和目标存储后保存。

## 运行备份

在向导的开始备份阶段选择刚创建的配置，执行“立即备份”。运行期间不要关闭 Agent、卸载 NAS 或修改目标存储凭据。

等待任务结束后，继续[验证备份结果](/zh/docs/getting-started/verify-backup)。
