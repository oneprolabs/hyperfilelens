# 配置 AI 模型

创建洞察会话前，需要由平台管理员配置 AI 模型。默认 Agent 模型负责对话、推理和答案生成；分析图片、扫描 PDF 或文档内图片时，还需要默认多模态模型。

| 模型角色 | 要求 | 用途 |
| --- | --- | --- |
| 默认 Agent 模型 | 必需 | 对话、推理、工具调用和答案生成 |
| 默认多模态模型 | 按需 | 图片、扫描 PDF 和文档内图片理解 |

纯文本首次体验只需要默认 Agent 模型。如果同一个模型同时满足对话和视觉能力要求，可以将其设置为两个默认角色；否则分别配置。

## 开始前准备

准备以下信息：

- 平台管理员账户；
- AI 模型供应商和模型 ID；
- 模型供应商要求使用的自定义 API 地址（如有）；
- 模型服务的有效 API Key；
- HyperFileLens 部署环境能够连接模型服务。

## 打开 AI 模型

1. 在安装结果的 `Access` 区域找到 `Platform Ops`，并在浏览器中打开其 `URL`。
2. 使用平台管理员账户登录。
3. 打开 **AI 引擎 → AI 模型**。
4. 选择 **添加 AI 模型**。

## 添加默认 Agent 模型

1. 选择模型供应商。
2. 选择模型或填写模型 ID。
3. 填写 **API Key**。模型供应商要求使用自定义地址时填写 **API 接口地址**；否则保持为空，使用供应商默认地址。
4. 保持模型为 **启用**。
5. 选择 **测试连接**，确认连接成功。
6. 选择 **添加模型**。
7. 在模型列表中选中该模型，然后选择 **更多操作 → 设置为默认 Agent 模型**。

## 配置默认多模态模型

需要分析图片、扫描 PDF 或文档内图片时：

1. 添加并测试一个支持视觉理解的模型；如果默认 Agent 模型同时支持视觉，可以继续使用同一个模型。
2. 保持模型为 **启用**。
3. 在模型列表中选中该模型，然后选择 **更多操作 → 设置为默认多模态模型**。
4. 使用一份包含图片或扫描页面的测试文档创建小范围会话，确认图像内容可以正常解析。

## 确认模型可用

继续前确认：

- 默认 Agent 模型状态为 **已启用**，并标记为 **默认 Agent 模型**；
- 需要处理视觉内容时，默认多模态模型状态为 **已启用**，并标记为 **默认多模态模型**；
- 两类模型的连接测试均成功；
- 打开 **新建对话** 时不再提示缺少模型。

API Key 属于敏感信息，只能填写在产品配置中，不要出现在截图、文档或公开 Issue 中。
