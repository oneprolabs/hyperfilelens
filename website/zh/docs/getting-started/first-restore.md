# 恢复测试文件

恢复验证是快速开始的最后一步。不要直接覆盖原文件，应恢复到一个独立测试目录。

## 执行恢复

1. 从刚验证的快照中选择一个测试文件。
2. 选择在线的恢复目标节点。
3. 选择一个空的测试目录作为恢复位置。
4. 首次恢复优先使用“跳过同名文件”。
5. 核对快照、文件、目标节点和目标路径后开始恢复。
6. 等待恢复任务完成。

## 验证恢复结果

在目标主机上打开恢复后的文件，并确认：

- 文件可以正常读取。
- 内容与备份前一致。
- 文件名和目录结构正确。
- 控制台任务结果与目标主机上的实际文件一致。

完成这一步，表示第一条数据保护链路已经可用。接下来可进入[备份与恢复](/zh/docs/backup-restore/)配置正式保护范围、调度和保留策略。
