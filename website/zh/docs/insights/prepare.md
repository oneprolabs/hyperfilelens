# 准备快照

智能洞察使用已经生成的备份快照。开始前应确认快照可用，并把数据范围控制在当前问题真正需要的文件或目录内。

## 1. 验证快照

在备份详情中确认：

- 快照状态为成功或部分成功。
- 快照包含可浏览的物理目录。
- 需要分析的文件位于该快照中。
- 文件类型和大小没有被备份过滤规则排除。

## 2. 控制数据范围

仅选择当前问题需要的文件或目录。较小、边界明确的数据范围可以减少准备时间、资源消耗和无关上下文。

不要选择包含密钥、访问令牌、个人敏感信息或无授权客户数据的目录，除非组织已明确允许相应处理方式。

## 3. 检查运行条件

创建会话还需要可用的默认 AI 模型和 Data Gateway。页面提示模型未配置时，请由平台管理员[配置 AI 模型](/zh/docs/insights/models)；备份仓库只能从私有网络访问时，请[使用 Private Data Gateway](/zh/docs/insights/data-gateway)。
