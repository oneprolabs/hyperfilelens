# 准备快照

智能洞察使用已经生成的备份快照，而不是源端当前文件。开始前应确认快照可用，并且它代表需要分析的数据版本。

## 1. 验证快照

打开备份源详情并选择 **Snapshot Points**，确认：

- 快照状态为 **Available**。
- 快照属于预期的备份源和仓库。
- 完成时间符合需要分析的数据版本。
- 快照包含可浏览的物理目录。
- 需要分析的文件位于该快照中。
- 文件类型和大小没有被备份过滤规则排除。

![Snapshot Points 中的可用快照，主机信息已经模糊处理，快照标识、时间、大小和文件数量保持可见](/docs/getting-started/snapshot-points-available.png)

选择 **Browse Files** 并找到一个已知文件后再进入 Insights。仅备份任务成功、但快照中没有所需文件，不能作为有效分析来源。

![快照浏览器中的合成测试文件，主机信息已经模糊处理，文档专用路径和文件名保持可见](/docs/getting-started/browse-snapshot-files.png)

## 2. 控制数据范围

仅选择当前问题需要的文件或目录。较小、边界明确的数据范围可以减少准备时间、资源消耗和无关上下文。

不要选择包含密钥、访问令牌、个人敏感信息或无授权客户数据的目录，除非组织已经批准对应处理路径。数据进入备份并不自动代表已经授权 AI 处理。

## 3. 检查运行条件

创建会话还需要：

- 可用的默认 Agent 模型；
- 需要理解图片或扫描文档时，可用的默认多模态模型；
- 可用的 Public Data Gateway，或能够访问仓库的在线 Private Data Gateway；
- 足够的组织和网关容量。

页面提示缺少条件时，先解决对应问题，再重新提交会话。
