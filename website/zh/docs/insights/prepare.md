# 准备快照和 Data Gateway

Copilot 会话创建失败通常来自四类前置条件：没有可用快照、未选择数据范围、没有可用网关，或平台未配置默认模型。

## 1. 验证快照

在备份详情中确认：

- 快照状态为成功或部分成功。
- 快照包含可浏览的物理目录。
- 需要分析的文件位于该快照中。
- 文件类型和大小没有被备份过滤规则排除。

## 2. 验证模型

平台需要配置默认 Agent 模型，才能创建会话。需要理解独立图片、文档内图片或 PDF 视觉内容时，还应配置默认多模态模型。

普通租户无法自行修复平台模型缺失，应把界面显示的模型就绪状态交给平台管理员处理。

## 3. 选择 Data Gateway

- 选择“自动”时，系统使用可用的默认公共 Data Gateway。
- 选择“手动”时，从当前用户可用的在线私有 Data Gateway 中选择。

当备份仓库位于私有网络或不允许平台网关访问时，应使用部署在同一可达网络中的私有 Data Gateway。

## 4. 控制数据范围

仅选择当前问题需要的文件或目录。较小、边界明确的数据范围可以减少准备时间、资源消耗和无关上下文。

不要选择包含密钥、访问令牌、个人敏感信息或无授权客户数据的目录，除非组织已明确允许相应处理方式。
