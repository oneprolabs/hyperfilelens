# 查看 AI 使用量

当前租户版本没有在 Insights 导航中提供 **AI Usage** 页面。打开旧的 `/insight/usage` 路径会返回 **AI Copilot**，因此不能把该路径当作实际使用量报表。

## 租户用户当前可以查看什么

与使用量或容量相关的状态分散在以下位置：

- **New Chat** 中的模型就绪和容量提示；
- Public 或 Private Data Gateway 是否可用；
- 等待网关时的队列位置；
- 会话中的准备和运行状态；
- 组织容量不足或模型不可用错误。

这些信息可以解释会话为什么能够或不能运行，但不等同于账单或完整历史用量。

社区版使用内置社区额度；官方 SaaS 的可用额度由平台侧管理，当前租户界面不提供完整额度和历史用量报表。

## 需要用量报表时

模型供应商账单、组织额度、Token 汇总和历史运行核算应由平台管理员提供。报告异常时，可以提供组织、会话时间、会话名称、运行状态和可见错误；未经批准不要附带用户问题、AI 回答、文件内容、凭据或注册命令。

AI 容量限制只影响 Insights 运行，不会使已有备份或恢复点失效。
