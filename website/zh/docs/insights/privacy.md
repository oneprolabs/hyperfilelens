# 会话与数据范围

每个会话都关联创建时选择的备份源、快照、文件范围和 Data Gateway。会话名称或聊天历史不会改变这一基础数据边界。

## 会话管理

可以在会话列表中查看历史对话，并根据当前版本提供的操作进行重命名、置顶或删除。删除会话不等同于删除源快照；删除快照也不应被理解为自动清理所有外部模型服务日志。

不再需要的会话应及时删除。共享截图前，应同时检查用户问题、AI 回答、引用路径和文件名是否包含敏感信息。

## 引用和依据

引用用于帮助定位回答依据，但不表示答案已经通过业务审核。遇到以下情况应回到原文件：

- 回答包含精确数字、日期或合同条款。
- 多个文件内容相互冲突。
- 引用范围不足以支持结论。
- 快照较旧，生产数据可能已经变化。

## 数据流边界

1. Agent 把生产文件写入受保护的备份仓库。
2. 用户从一个具体快照中选择文件或目录。
3. Data Gateway 在隔离工作区准备所选范围。
4. AI 引擎和配置的模型处理该会话需要的内容。

实际数据是否离开私有网络，还取决于选择的公共或私有网关、模型提供商和部署配置。使用外部模型 API 前，应核对组织的数据处理政策、模型服务条款和日志保留设置。

## 权限变化

用户失去备份源或组织权限后，不应继续依赖旧会话作为访问入口。管理员应结合账户、快照、会话和网关工作区进行权限回收与清理验证。
