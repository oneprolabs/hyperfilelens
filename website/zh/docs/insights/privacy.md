# 会话与数据范围

每个会话都绑定创建时选择的备份源、一个快照时间点、文件或目录范围、分析类型和 Data Gateway。重命名会话或继续提问不会改变这一基础数据边界。

## 会话管理

会话列表包含历史问题和回答。共享截图前，应同时检查会话名称、用户问题、AI 回答、引用、路径、文件名、账户、主机、仓库和 Gateway 标识。

## 引用和依据

引用用于帮助定位回答依据，但不表示答案已经通过业务审核。遇到以下情况应回到原文件：

- 回答包含精确数字、日期或合同条款。
- 多个文件内容相互冲突。
- 引用范围不足以支持结论。
- 快照较旧，生产数据可能已经变化。

## 数据流边界

1. Agent 把生产文件写入受保护的备份仓库。
2. 用户从一个具体快照中选择文件或目录。
3. Data Gateway 在隔离工作区准备所选范围。
4. AI 引擎和配置的模型处理该会话需要的内容。

实际数据是否离开私有网络，取决于网关位置、模型 Endpoint、供应商和部署配置。Private Data Gateway 会把恢复和数据准备保留在该网关，但不代表外部模型 API 也位于私有网络。

## 权限变化

用户失去备份源或组织权限后，不应继续依赖旧会话作为访问入口。管理员应结合账户、快照、会话和网关工作区进行权限回收与清理验证。

删除或重命名会话不等于删除源快照；删除快照也不应被理解为会自动清除外部模型供应商保留的日志。应按照组织要求分别处理账户、快照、会话、网关工作区和供应商侧保留数据。
