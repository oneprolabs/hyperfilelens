# 创建洞察会话

打开<span class="hfl-path">洞察 → AI Copilot</span>并选择“新建对话”。

## 创建会话

1. 选择一个已有备份配置作为数据来源。
2. 选择最新快照或指定快照时间点。
3. 从快照目录中添加至少一个文件或目录。
4. 选择公共 Data Gateway 自动处理，或者手动选择在线私有 Data Gateway。
5. 核对所选备份源、快照时间、范围和网关。
6. 创建会话，等待数据准备完成。

如果创建按钮不可用，页面会提示当前阻塞条件。按提示补齐备份源、快照、数据范围、网关或默认模型，不要连续重复提交相同请求。

## 提问方式

先从范围明确、可以核对的问题开始：

- “列出此目录中的主要文档及其主题。”
- “这份协议的有效期和终止条件是什么？请给出依据。”
- “比较两个版本目录中的关键变更。”
- “定位实现某项功能的主要文件，并说明调用关系。”

问题中说明需要的输出格式、时间范围和判断标准。范围过大的提问应拆成多轮，并在结论前要求指出来源。

## 使用回答

- 打开引用或相关文件，确认回答与原文一致。
- 对重要数字、日期、责任边界和操作命令进行人工复核。
- 回答缺少依据时，缩小问题范围或明确要求引用。
- 回答似乎来自旧内容时，核对会话绑定的快照时间。

AI Copilot 适合辅助理解和定位，不应成为未经复核的生产变更、法律或财务决策依据。
