# 配置 AI 模型

智能洞察需要可用的默认 Agent 模型。需要理解图片、扫描 PDF 或文档内图片时，还需要默认多模态模型。

## 谁负责配置

模型配置属于平台管理能力。官方 SaaS 的普通租户用户不能从租户 **Insights** 导航管理供应商凭据；New Chat 页面提示模型不可用时，应联系平台管理员。

Community 或平台管理员在平台运维控制台中管理 AI 模型。具体访问地址取决于部署方式，并与租户控制台隔离。

## 添加模型

1. 使用平台管理员账户打开平台 AI 模型设置。
2. 添加模型并选择供应商。
3. 填写模型名称、模型 ID、API 地址和访问凭据。
4. 测试连接并保存。
5. 将可用于对话的模型设为默认 Agent 模型。
6. 如需图片和扫描文档理解，将兼容且处于活动状态的模型设为默认多模态模型。
7. 创建小范围测试会话，核对回答和引用。

## 配置要求

- 使用与模型供应商实际服务兼容的模型 ID 和 API 地址。
- API 凭据属于秘密，只能保存在批准的产品配置中，不要写入文档、截图、Issue 或终端历史。截图无法避免时，让字段保持为空或对完整值进行不透明覆盖；禁止模糊秘密。
- 修改默认模型后创建测试会话，确认文本回答和所需的视觉能力均正常。
- 停用或删除默认模型前，先为相关能力指定新的默认模型。

使用外部模型服务前，应确认组织允许相应的数据处理位置、服务条款和日志保留方式。

## 用户如何验证就绪

租户用户通过实际行为验证配置：

- **New Chat** 没有缺少模型的提示；
- 需要的分析类型可用；
- 选择所有必填项后 **Start Chat** 可用；
- 数据准备达到 **Ready**，测试问题能够返回回答。

停用或替换默认模型前，先指定替代模型并完成测试会话。即使使用 Private Data Gateway，外部模型服务的位置、条款和日志保留仍属于数据处理决策。
