# 配置 AI 模型

智能洞察需要可用的默认 Agent 模型。需要理解图片、扫描 PDF 或文档内图片时，还应配置默认多模态模型。模型配置属于平台管理能力，普通组织用户只需关注页面显示的模型是否就绪。

## 添加模型

1. 使用平台管理员账户进入<span class="hfl-path">平台运维 → AI 引擎 → AI 模型</span>。
2. 添加模型并选择供应商。
3. 填写模型名称、模型 ID、API 地址和访问凭据。
4. 测试连接并保存。
5. 将可用于对话的模型设为默认 Agent 模型。
6. 如需图片和扫描文档理解，将具备视觉能力的模型设为默认多模态模型。

## 配置要求

- 使用与模型供应商实际服务兼容的模型 ID 和 API 地址。
- API 凭据只保存在产品配置中，不要写入文档、截图或公开 Issue。
- 修改默认模型后创建测试会话，确认文本回答和所需的视觉能力均正常。
- 停用或删除默认模型前，先为相关能力指定新的默认模型。

使用外部模型服务前，应确认组织允许相应的数据处理位置、服务条款和日志保留方式。
