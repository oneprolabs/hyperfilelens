# 恢复文件和目录

恢复可以使用预设恢复计划，也可以创建新的手动恢复任务。需要调整快照、目录、目标节点或重名策略时，使用手动恢复。

## 开始前检查

- 选择的备份源至少有一个成功或部分成功快照。
- 快照包含可用物理目录。
- 恢复目标 Agent 在线，目标目录存在且可写。
- 目标磁盘有足够空间。
- 已明确重名文件采用“跳过”还是“覆盖”。

## 手动恢复

1. 在备份向导或快照详情中选择“创建恢复任务”。
2. 选择执行恢复的目标节点。
3. 选择备份和具体快照时间点。
4. 为每个备份选择整个快照、目录或单个文件作为恢复范围。
5. 选择目标目录，核对“恢复范围 → 恢复目录”的映射。
6. 设置重名策略：
   - **跳过**：保留目标端已有同名文件。
   - **覆盖**：使用备份内容替换目标端同名文件。
7. 核对确认页后开始恢复。

首次恢复或不确定目标内容时优先选择“跳过”，并恢复到独立测试目录。覆盖操作可能替换当前文件，提交前必须核对目标节点和路径。

## 使用恢复计划

恢复计划使用创建备份配置时预设的范围、目标和冲突策略，并固定从最新可用快照执行。没有配置恢复计划的源端会被跳过，界面会在提交前显示实际执行范围。

恢复计划适合目标位置固定、需要重复演练或快速恢复的业务。计划包含恢复范围、目标节点、目标目录和重名策略。当恢复目标或目录经常变化时，使用手动恢复更安全；目标固定并需要定期验证时，再配置恢复计划。

## 验证结果

恢复任务完成后，在目标主机检查实际文件，而不只查看控制台状态。若任务被停止，目标目录可能包含不完整文件；清理或核对后再重新恢复。

恢复失败时记录失败路径、目标节点、错误编号和任务时间，然后查看[备份、存储与恢复](/zh/docs/troubleshooting/protection)。
