# 备份与恢复

HyperFileLens 的数据保护流程由备份源、备份配置、目标存储、任务和快照组成。恢复不是备份任务的附属状态，而是验证备份是否真正可用的必要步骤。

## 完整流程

1. [准备备份源和目标存储](/zh/docs/backup-restore/prepare)。
2. [创建并运行备份](/zh/docs/backup-restore/create-backup)。
3. [查看任务与验证快照](/zh/docs/backup-restore/snapshots)。
4. [恢复文件和目录](/zh/docs/backup-restore/restore)。
5. 根据恢复目标设置[策略、保留与恢复计划](/zh/docs/backup-restore/policies)。

## 三个关键判断

- **源端可读**：Agent 或 Proxy 在线，所选目录存在且具备读取权限。
- **目标可写**：对象存储、NAS 或本地磁盘完成验证，并由当前配置拥有明确的仓库位置。
- **快照可用**：任务成功或部分成功，快照包含可浏览、可恢复的物理目录。

部分成功不等于全部数据受保护。必须查看失败目录、跳过项和实际数据量，再决定该快照是否满足恢复要求。

## 推荐做法

- 首次配置先保护一个范围明确的小目录，完成备份和恢复闭环后再扩大范围。
- 目标路径和对象前缀专库专用，避免与其他产品或独立 HyperFileLens 仓库混用。
- 为关键数据定期执行恢复验证，而不是只观察备份任务状态。
- 变更备份目录、过滤规则和保留策略后，重新检查下一次快照内容。
