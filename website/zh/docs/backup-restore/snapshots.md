# 查看任务与快照

任务状态说明执行是否结束，快照内容说明实际保护了什么。两者必须结合检查。

## 查看任务

在备份源详情或<span class="hfl-path">租户运维 → 任务列表</span>中检查：

- 开始、结束时间和总耗时。
- 已扫描与已传输数据量。
- 成功、部分成功、失败或停止状态。
- 失败目录、跳过文件和 Agent 返回的错误信息。

Agent 离线时，控制平面可能需要等待重新连接才能确认最终任务状态。不要在状态仍确认中时立即删除配置或重新注册节点。

## 验证快照

打开备份详情并选择快照时间点：

1. 确认快照来自正确备份源和目标仓库。
2. 对比完成时间和预期调度时间。
3. 对比总数据量与源目录规模。
4. 浏览快照目录，查找一组已知文件。
5. 检查关键子目录是否存在，文件名和层级是否正确。

只有成功或部分成功且包含可用物理目录的快照才能用于恢复。部分成功快照可能仍可恢复已完成目录，但必须确认缺失范围不会影响使用。

## 恢复验证

选择少量文件恢复到独立测试目录，并验证：

- 文件可以打开，内容与源端预期一致。
- 目录结构和文件名完整。
- 重名策略按选择执行。
- 恢复任务记录与目标节点实际结果一致。

定期恢复验证比单纯保留更多快照更重要。关键系统应记录最近一次成功恢复验证的时间、范围和结果。
