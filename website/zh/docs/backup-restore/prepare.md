# 准备备份源和目标存储

备份源决定从哪里读取数据，目标存储决定快照写到哪里。两者之间必须存在一条实际可用的数据路径，仅控制台能够访问双方并不足够。

## 备份源

### 主机文件

在 Linux、Windows 或 macOS 主机上部署 Agent。节点在线后，在<span class="hfl-path">数据保护 → 源端资源</span>中确认目录可以浏览。

选择目录时避免：

- 操作系统伪文件系统、设备文件或临时挂载点。
- Agent 账户无权读取的目录。
- 会无限增长或包含大量无业务价值缓存的路径。
- 同一数据通过多个重叠根目录被重复选择。

### NAS 共享

添加 NAS 源时，配置共享协议、地址和凭据，并选择能够访问该共享的 Proxy。未绑定 Proxy 的模式要求源端主机自行直接挂载或访问 NAS，不适用于所有平台和网络结构。

SMB 中文或其他非 ASCII 文件名显示异常时，应检查 Linux Proxy 的 `nls_utf8` 模块和挂载字符集，而不是在控制台中重新命名原文件。

## 目标存储

### 对象存储

支持 AWS S3、阿里云 OSS、华为云 OBS 和受支持的通用 S3 兼容服务。需要正确配置：

- 服务商或自定义端点。
- 区域、存储桶和对象前缀。
- URL 访问方式与 TLS 设置。
- 具备列出、读取、写入和删除所需对象的最小权限凭据。

### NAS

NAS 可以绑定 Proxy，由 Proxy 挂载并向备份源提供仓库访问。未绑定 Proxy 的直接 NAS 目标当前只对已确认的 Linux 源端开放；Windows、macOS 或平台未确认的源端应使用绑定 Proxy 的 NAS、Proxy 本地磁盘或对象存储。

### Proxy 本地磁盘

选择 Proxy 主机上的专用绝对路径。应预留快照增长、维护和恢复读取空间，不要使用系统临时目录或其他应用数据目录。

## 保存前检查

- 目标位置未被其他仓库占用。
- 访问凭据只具备必要范围，并已从截图和日志中脱敏。
- 源端到对象存储或 Repository Server 的网络路径可达。
- 主机时间准确，证书链可信。
- 容量和保留周期能覆盖预期数据增长。
