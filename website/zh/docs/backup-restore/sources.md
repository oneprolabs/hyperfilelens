# 管理备份源

备份源是需要保护的数据入口。HyperFileLens 可以保护安装 Agent 的主机文件，也可以通过 Proxy 访问 NAS 共享。

## 主机文件

在 Linux、Windows 或 macOS 主机上部署 Agent。节点在线后，在<span class="hfl-path">数据保护 → 源端资源</span>中确认目录可以浏览。

选择目录时避免：

- 操作系统伪文件系统、设备文件或临时挂载点。
- Agent 运行账户无权读取的目录。
- 大量无业务价值的缓存或可重新生成的数据。
- 通过多个重叠根目录重复选择同一批文件。

## NAS 共享

添加 NAS 源时，配置共享协议、地址和凭据，并选择能够访问该共享的 Proxy。保存前确认共享路径、协议、凭据和字符集正确。

如果中文或其他非 ASCII 文件名显示异常，应检查 Proxy 的挂载字符集和系统支持，不要通过重命名生产文件绕过问题。

## 日常检查

- 节点或 Proxy 保持在线。
- 目录可以浏览，权限变化后及时重新验证。
- 实际数据范围与备份配置一致。
- 节点版本与当前控制平面兼容。
