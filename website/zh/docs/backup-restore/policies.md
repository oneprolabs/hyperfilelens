# 策略与保留

策略决定何时运行和如何处理源数据，保留规则决定快照生命周期。

## 备份策略

策略至少需要覆盖：

- 运行频率和时间窗口。
- 文件过滤和不可读项处理。
- 是否限制在所选文件系统内。
- 压缩及其他影响传输的选项。

调度频率应根据恢复点目标和数据变化速度确定。高频调度不会自动解决源端长时间离线、仓库不可达或任务运行时间超过间隔的问题。

## 保留规则

保留周期必须同时考虑业务恢复要求和目标存储容量。缩短保留期会减少可选历史时间点；延长保留期会持续增加仓库容量和维护开销。

修改保留规则前确认：

- 最短需要回溯到哪个时间点。
- 是否存在合规或审计保留要求。
- 最近是否完成过恢复验证。
- 目标仓库是否有足够增长空间。

## 文件过滤

排除规则适合缓存、临时文件和可重新生成的数据。不要仅为了让首次任务更快而排除尚未确认的数据范围。

规则变更只影响后续快照，不会补充已有快照中从未备份的文件。变更后应浏览下一次快照进行确认。
