# 组织

组织是成员、备份资源、任务和业务数据的工作空间。打开<span class="hfl-path">配置管理 → 治理 → 组织</span>，确认当前工作在正确的组织上下文中。

## 查看组织信息

在组织页面核对：

- 组织名称与标识信息；
- 与当前登录账户的关系（例如是否为所有者）；
- 页面提示的组织级状态或限制说明。

顶部组织切换器用于在多个组织之间切换。切换后，治理、数据保护、洞察和运维监控中的数据范围都会随之变化。

## 维护组织信息

具备组织管理权限的成员可以更新允许编辑的组织字段。保存前确认名称等对外可见信息符合组织规范。

不要把组织页面当作平台级安装或许可证管理入口。实例许可证、实例容量池等由管理控制台中的平台治理页面处理。

## 变更组织前

停用或删除组织通常在<span class="hfl-path">管理控制台 → 治理 → 组织</span>中由平台管理员执行，会影响该组织下的成员访问与资源可见性；仅在明确业务要求且已完成数据与权限评估后操作。

安装管理员身份与组织所有者身份不同：安装管理员用于平台安装与管理控制台，不自动等同于某个租户内的业务管理员角色。谁可以进入组织并执行操作，由[成员](/zh/docs/governance/members)和[角色与权限](/zh/docs/governance/roles)决定。
