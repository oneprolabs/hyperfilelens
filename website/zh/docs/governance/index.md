# 治理概述

治理用于管理组织内的成员、权限、资源范围和用量配额。组织侧在<span class="hfl-path">配置管理 → 治理</span>中完成日常管理；需要调整实例级配额或审批申请时，由平台管理员在管理控制台处理。

完整组织治理能力（预设角色、组、资源目录、用量与配额申请及平台审批）由企业版提供。社区版若看不到对应菜单，表示当前部署未启用该能力。

## 日常使用流程

1. 在[组织](/zh/docs/governance/organization)确认当前工作空间。
2. 了解[角色与权限](/zh/docs/governance/roles)中的默认角色，再在[成员](/zh/docs/governance/members)中分配。
3. 需要按团队缩小资源范围时，配置[组](/zh/docs/governance/groups)，并在[资源](/zh/docs/governance/resources)中核对归属。
4. 在[用量与配额](/zh/docs/governance/usage)中跟踪限额；不足时提交申请，由平台审批后生效。

**所有者** 是组织身份，不是可在角色列表中创建或删除的预设角色行。新注册用户不会自动获得高权限角色；访问范围仍取决于组织成员关系与角色分配。


## 组织侧与平台侧

| 范围 | 入口 | 典型工作 |
| --- | --- | --- |
| 组织治理 | <span class="hfl-path">配置管理 → 治理</span> | 组织信息、成员、组、角色、资源、用量与申请 |
| 平台治理 | <span class="hfl-path">管理控制台 → 治理</span> | 组织列表、平台角色、订阅套餐、组织配额、[配额申请审批](/zh/docs/governance/usage#平台审批配额申请) |

组织成员提交配额申请不会获得修改配额的权限；只有具备组织配额管理权限的平台管理员可以审批并写入限额。

任务失败、节点离线等运行问题，请在[任务、告警与审计](/zh/docs/deployment/operations)中查看。告警规则与通知渠道属于运维监控，不属于治理侧栏。
