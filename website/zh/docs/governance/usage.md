# 用量与配额

用量页面展示当前组织的许可证状态、配额限额与实际占用。打开<span class="hfl-path">配置管理 → 治理 → 用量</span>进行查看；需要提高限额时提交申请，由平台管理员在管理控制台审批。

## 查看用量

在用量页面确认：

- 各配额项的当前使用量与上限；
- 是否接近或已达到限额；
- 请求历史中的申请状态（企业版启用配额提额后可见）。

配额用尽时，相关创建或运行操作可能被拒绝，并提示打开用量或联系平台管理员。直接修改组织配额属于平台治理能力，组织侧申请不会自动提升权限。

## 提交配额申请

具备用量管理权限的成员可以提交申请：

1. 在用量页面选择<span class="hfl-ui">申请提额</span>，并选择需要提高的配额项。
2. 填写更高的申请限额，以及申请理由。
3. 提交后，在<span class="hfl-ui">请求历史</span>中跟踪状态。
4. 同一配额项在已有待审核申请时，需等待处理完成后再提交新的申请，避免重复处理。

仅具有用量查看权限时，可以查看限额与占用，但不能提交或取消申请。

### 申请状态

界面中的状态与含义如下：

| 状态 | 含义 |
| --- | --- |
| 待审核 | 已提交，等待平台审批 |
| 已批准 | 审批通过，且限额已成功写入 |
| 应用失败 | 审批通过，但写入限额失败；组织配额保持原值，需平台侧排查后处理 |
| 已拒绝 | 审批拒绝，限额不变 |
| 已取消 | 申请人在审批前取消 |

批准必须以实际写入成功为准：状态为<span class="hfl-ui">应用失败</span>时，不能当作限额已经提高。

对待审核申请，可选择<span class="hfl-ui">取消</span>。取消后该申请不再进入批准流程，配额保持不变。

## 平台审批配额申请

平台管理员打开<span class="hfl-path">管理控制台 → 治理 → 配额申请</span>：

1. 按组织、状态或关键字筛选待审核申请。
2. 核对组织、配额项、当前限额、申请限额与说明。
3. 选择<span class="hfl-ui">批准</span>或<span class="hfl-ui">拒绝</span>，并填写决策说明。
4. 批准时通过现有组织配额管理机制写入新限额；写入失败时申请状态为<span class="hfl-ui">应用失败</span>，而不是静默成功。
5. 申请人会收到站内通知，可在用量页的请求历史中查看结果。

审批权限与提交权限分离：组织成员提交申请，不会获得管理控制台中的配额管理权限。平台侧仍受实例容量、许可证等现有约束；审批不能绕过这些限制。

不经过申请单、直接调整组织配额，仍可在管理控制台的组织或订阅相关页面完成，与申请审批相互独立。

## 日常检查

- 关键配额项未长期逼近上限；成员、备份或网关扩容前先看用量。
- 待审核申请有人跟进；状态为<span class="hfl-ui">应用失败</span>的申请已转平台侧排查。
- 容量或任务异常时，结合[任务、告警与审计](/zh/docs/deployment/operations)排查运行侧问题。
